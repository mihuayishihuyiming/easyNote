# 微信小程序上架指南（简易记账）

本文整理从零把「简易记账」小程序发布上架的完整流程，包括注册、备案、代码上传、审核与发布，以及常见驳回原因和避坑点。信息基于微信官方规则整理（2023 年 9 月起境内小程序强制 ICP 备案），具体以微信公众平台后台的实际提示为准。

---

## 一、先决定主体：个人 or 企业

| 对比项 | 个人主体 | 企业 / 个体工商户 |
| --- | --- | --- |
| 所需材料 | 身份证 + 本人手机号 | 营业执照 + 法人/负责人信息 |
| 注册费用 | 免费 | 免费 |
| 微信认证 | 非商用工具类一般无需认证 | 商用必须认证，300 元/年（个体户常享 30 元/年优惠） |
| 可做类目 | 仅限工具类（如计算器、个人记账） | 类目范围更广 |
| 微信支付 | 不可用 | 可用（需额外开通商户号） |
| 备案 | 身份证 + 人脸识别即可 | 需营业执照等主体资料 |

「简易记账」是纯本地单机工具，**个人主体即可免费上架**，这是最省事的方式。

> ⚠️ 注意：如果做成「多人共享账本、账本分享」等功能，会被归入「社交-笔记」类目，个人主体未开放，只能走企业主体。本项目的纯本地记账不涉及此问题。

---

## 二、注册小程序账号

1. 打开[微信公众平台](https://mp.weixin.qq.com)，点右上角「立即注册」。
2. 选择账号类型「**小程序**」。
3. 用未被注册过的邮箱接收激活邮件，激活后进入下一步。
4. 选择主体类型（个人 / 企业 / 个体工商户），按提示填写主体信息：
   - 个人：姓名、身份证号、手机号、短信验证码；
   - 手机微信扫码做身份验证，**扫码微信的实名信息必须与填写的身份信息一致**。
5. 注册完成，登录小程序后台。

---

## 三、完善小程序基础信息

登录后台后，在「设置 → 基本设置」完成：

- **名称**：如「简易记账」。名称不得包含广告、敏感词，建议 2~8 个汉字，好记且与功能一致。
- **头像**：清晰的图标，200×200 以上。
- **简介**：如实描述功能，如「离线计算器式记账工具，数据保存在本机」。
- **类目**：在「设置 → 基本设置 → 服务类目」选择与功能一致的类目。记账/计算器属于**工具类目**下的子类目，个人主体选择可用项即可。

> 提示：类目与功能不符是审核驳回的高频原因；选类目时优先选「工具」相关。

## 四、获取 AppID 并替换

1. 后台「开发 → 开发管理 → 开发设置」中复制 **AppID**。
2. 用微信开发者工具打开本项目，把 `project.config.json` 里的 `"appid": "touristappid"` 替换为你的 AppID。
3. 同时在后台「管理 → 成员管理」把你的微信号添加为「开发者」（或项目管理员），否则工具无法上传代码。

## 五、本地开发与真机预览

1. 下载[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（稳定版）。
2. 「导入项目」选择本项目目录，点「编译」即可在模拟器运行。
3. 工具栏「预览」→ 手机微信扫码，真机体验。
4. 本程序**没有任何网络请求**，全部数据存在本机，无需配置服务器域名，也不涉及隐私接口。

## 六、上传代码（提交开发版本）

1. 在开发者工具工具栏点「**上传**」。
2. 填写版本号（如 `1.0.0`）和版本备注（如「首版：计算器式离线记账」）。
3. 上传成功后，进入小程序后台「管理 → 版本管理」，可以看到「开发版本」列表。

## 七、ICP 备案（2023 年 9 月起强制，未备案无法发布）

根据工信部要求，**所有境内上架的小程序必须完成 ICP 备案**；未备案无法发布，已上架未备案的会被清退。备案免费。

入口：后台首页顶部提示「去备案」，或「设置 → 基本设置 → 小程序备案」。

备案流程：

1. **填写备案信息**：主体信息（个人：身份证、手机号、通讯地址）和服务信息。
2. **平台初审**：微信平台审核材料，一般 1~3 个工作日。
3. **工信部短信核验**：初审通过后，工信部会发送验证短信（发送号码 **12381**），收到后**务必在 24 小时内**登录 [beian.miit.gov.cn](https://beian.miit.gov.cn) 完成短信核验。
4. **管局审核**：由属地通信管理局审核，一般 3~20 个工作日。
5. **备案成功**：后台显示备案状态为「已备案」后，才能发布上线。

> 备案和审核可以并行：可以先提交代码审核，同时做备案；但**发布**必须等备案完成。

## 八、提交审核

1. 后台「管理 → 版本管理 → 开发版本」，找到刚上传的版本，点「**提交审核**」。
2. 填写审核信息：
   - 功能页面：如「首页（记一笔 / 明细）」；
   - 测试说明：如「无需登录，纯本地记账工具，无账号体系，直接体验」；
   - 个人主体注意版本描述要如实、克制，不要写与功能无关的内容。
3. 提交后等待审核，官方周期一般为 **1~7 个工作日**（多数 1~3 天通过）。

## 九、发布上线

1. 审核通过后，在「版本管理 → 审核版本」点「**提交发布**」。
2. 可选择**全量发布**（一次覆盖所有用户）或**分阶段发布**（先小范围灰度，再逐步放量）。
3. 发布后进入「线上版本」，小程序即可被搜索、扫码使用。

## 十、常见驳回原因与避坑

| 驳回原因 | 如何避免 |
| --- | --- |
| 类目与功能不符 | 选择「工具」类目，简介与类目保持一致 |
| 名称/头像违规 | 避免「官方」「旗舰」等词，头像不要带水印广告 |
| 描述夸大 | 如「最专业」「一键赚钱」等绝对化/广告用语不要出现 |
| 涉及个人主体未开放类目 | 不做多人账本分享、不做支付、不做资讯内容 |
| 测试内容残留 | 上线前清空示例数据（本项目明细页底部有「清空全部数据」） |
| 需要用户协议/隐私指引 | 本程序不用隐私接口；若以后接入定位、相册、手机号等，需在后台配置《用户隐私保护指引》并申请对应权限 |

## 十一、费用与周期速览

| 项目 | 费用 | 周期 |
| --- | --- | --- |
| 注册账号 | 免费 | 当天 |
| 微信认证（个人非商用可不做） | 个人一般不收；企业 300 元/年，个体户常 30 元/年 | 1~5 个工作日 |
| ICP 备案 | 免费 | 一般 1~4 周 |
| 代码审核 | 免费 | 一般 1~3 个工作日 |
| 合计最快路径（个人主体） | 0 元 | 约 1~2 周（主要等备案） |

## 十二、后续迭代建议

- 支持选择记账日期、月/年统计图表（Canvas 或 ECharts 组件）；
- 支持多账本切换、数据导出（分享文件或复制文本）；
- 如需要多端同步或云备份，可接入微信云开发（个人主体可用），但要重新评估隐私与备案说明；
- 若要商用或接入微信支付，需改用企业/个体工商户主体并完成微信认证。

## 十三、常见问题

**Q：个人主体上架后，可以分享给朋友使用吗？**

A：可以。小程序发布后，任何用户都能通过**搜索名称、扫码、好友转发**等方式使用；朋友们各自在手机上独立记账，数据互不影响，只要功能保持「单机工具」定位即可（本项目已支持右上角转发给好友/朋友圈）。

但个人主体有几个边界需要注意：

- **不能做多人共享账本**：账本多人查看、协作编辑、好友互动等功能会被判定为「社交-笔记」类目，个人主体未开放，必须换企业/个体工商户主体；
- **不能做经营性功能**：微信支付收款、售卖商品/服务、虚拟支付、广告投放等，个人主体均不可用；
- **云端同步不等于可以共享**：技术上可以用微信云开发做备份，但只要功能涉及多人共享账本，审核时仍会按社交类目处理。

一句话总结：**分享给朋友各记各的账 → 个人主体没问题；多人共用一个账本 → 需要企业主体。**
